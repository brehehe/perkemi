# Laravel + Inertia Workflow

## Architecture

Laravel
↓
Route
↓
Controller
↓
Inertia
↓
React Page
↓
React Components

---

## Discovery

Inspect:

- routes
- controllers
- requests
- policies
- models
- resources/js
- Pages
- Components
- Layouts
- Hooks
- Types
- Tailwind
- Vite

Use existing conventions.

---

## Backend

Change backend only when required.

Preserve:

- validation
- authorization
- authentication
- business logic
- existing contracts

---

## Inertia

Check:

- props
- shared props
- lazy/deferred data
- partial reloads
- pagination
- payload size

Avoid oversized page props.

---

## React

Use:

- TypeScript
- reusable components
- typed props
- clear state management
